# Tempora – Temperature Converter

A modern, responsive temperature conversion website designed to provide a simple and interactive way to convert temperatures between Celsius, Fahrenheit, and Kelvin. Tempora combines accurate temperature calculations with an elegant user interface, temperature insights, and conversion history.

## 🌐 Project Overview

Tempora is a frontend web development project created as part of the **Oasis Infobyte Web Development and Designing Internship – Level 1, Task 3**.

The project focuses on building an interactive temperature converter with responsive layouts, input validation, dynamic temperature insights, and browser-based storage functionality.

## ✨ Features

- Modern and responsive user interface.
- Convert temperatures between Celsius (°C), Fahrenheit (°F), and Kelvin (K).
- Real-time temperature conversion.
- Quick temperature presets for faster conversions.
- Temperature insights based on the entered value.
- Interactive visual temperature indicator.
- Recent conversion history using Local Storage.
- Copy converted results to the clipboard.
- Input validation, including absolute-zero restrictions.
- Reset functionality to clear converter results.
- Interactive mobile navigation.
- Responsive design for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **HTML5** – Website structure and semantic content.
- **CSS3** – Styling, layouts, animations, and responsive design.
- **JavaScript (ES6)** – Temperature conversion logic, validation, DOM manipulation, and interactivity.
- **Local Storage** – Saving recent conversion history in the browser.
- **Google Fonts** – Modern typography.

## 📐 Temperature Conversion Formulas

Tempora uses mathematical formulas to convert temperatures between the three supported units.

**Celsius to Fahrenheit**

°F = (°C × 9/5) + 32

**Fahrenheit to Celsius**

°C = (°F − 32) × 5/9

**Celsius to Kelvin**

K = °C + 273.15

**Kelvin to Celsius**

°C = K − 273.15

**Fahrenheit to Kelvin**

K = (°F − 32) × 5/9 + 273.15

**Kelvin to Fahrenheit**

°F = (K − 273.15) × 9/5 + 32

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the Tempora project folder.

3. Open `index.html` in your preferred web browser.

4. Enter a temperature value and select the input unit.

5. Click the **Convert** button to view the converted results.

No additional installations or dependencies are required.

**Note:** Clipboard functionality may require a secure browser context, such as HTTPS or localhost.
