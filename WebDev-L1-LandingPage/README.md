# NexaFlow AI – Intelligent Workflow Automation

A modern, responsive landing page designed for NexaFlow AI, a conceptual AI-powered workflow automation platform. The website showcases how intelligent automation can simplify business processes, improve productivity, and help teams work smarter.

## 🌐 Project Overview

NexaFlow AI is a frontend web development project created as part of the **Oasis Infobyte Web Development and Designing Internship – Level 1, Task 1**.

The project focuses on creating an engaging, visually appealing landing page with modern UI design, responsive layouts, and interactive elements.

## ✨ Features

- Modern and responsive landing page.
- Sticky navigation bar with smooth section navigation.
- Attractive hero section with call-to-action buttons.
- Interactive platform features section.
- Step-by-step workflow presentation.
- Customer stories and testimonials.
- Pricing plans section.
- Contact section.
- Mobile-friendly navigation.
- Smooth scrolling and interactive JavaScript elements.
- Modern typography, gradients, and animations.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling, layouts, animations, and responsiveness.
- **JavaScript** – Interactive functionality.
- **Google Fonts** – Typography.
